Your browser is the studio.

Fieldwork is an original, entirely local four-track sequencer. There are no samples, remote models, analytics, or provider calls. Its drum kit and three melodic voices are synthesized in this file.

Arrange

The canvas is always eight bars of 4/4. Select a clip to edit it. Drag clips by whole bars; resize them by their right edge. Clips cannot overlap on the same track. Delete or shorten a clip to make room for another.

Write

Click the note grid to draw. Drag notes vertically or horizontally, and drag their right edge to change duration. Use the velocity control for the selected note. With no note selected, length and velocity set the defaults for new notes. Click a piano key to audition it.

Evolve clip creates a seeded, local pattern variation—not an AI or network operation. Every musical edit, including evolution, is undoable.

Shortcuts

Space play/pause · Ctrl/⌘ Z undo · Ctrl/⌘ Shift Z redo · Ctrl/⌘ S browser save · Delete selected note or clip. Arrow keys move a selected note; Shift ←/→ changes its length.

Keep it / take it

Save browser and Reload use localStorage. Browser storage can be cleared, so use Project ↓ for a portable editable JSON backup. Open .json restores it.

WAV export is stereo 16-bit PCM at 44,100 Hz, using the same render as playback. Muting, soloing, levels, and pan are included. The file is exactly eight bars at the current tempo; release tails are cropped with a short end fade. Peak protection only attenuates, with a −0.82 dBFS sample ceiling.
