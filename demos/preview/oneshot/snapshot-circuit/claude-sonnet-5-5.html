Marrow Lane Pantry GP

An invented room — a pantry table under a gingham cloth — raced as a toy-car circuit. The track loops around a still life whose five landmarks are measured below.

1 · Reference landmarks (measured)

Green + = centroid measured from the reference image pixels. White ○ = the level's actual collision object ÷ 5 (world→reference scale). Tolerance: centre ≤ 1.5 ref-px (0.47 % of image width), extent ≤ 2 ref-px. "Gap" = clearance between object and track centreline (must be ≥ 16 world-px so the lane stays drivable).
