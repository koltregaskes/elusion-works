The source / Original vector still life

A room that never existed.

Before there was a circuit, there was this still life. The level adds a taped racing line but preserves all five object anchors, sizes and rotations in the same 1200 × 800 coordinate space.

Acknowledgment / Design intent

Concept credit: Shipper's example of translating a still-life reference into a racing level. This is an independent implementation with an invented room and original artwork; no Shipper assets are reproduced.

The source is intentionally a vector still life, not a photograph. Its five measured landmarks become solid objects in the playable level. Driving off the tape slows you down; checkpoints must be crossed forward and in order.
